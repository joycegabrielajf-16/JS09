📖 O que são Eventos DOM?

Eventos DOM são ações que ocorrem na página web, como cliques, carregamento da página, mudanças em formulários, entre outros.

Os exemplos abaixo mostram os principais eventos DOM em ação.

📌 Exemplos

1 Evento onclick onclick

📌 Descrição:

O evento onclick é disparado quando o usuário clica em um elemento.

Funcionamento: Ao clicar no botão, uma caixa de alerta é exibida com a mensagem "Você clicou no botão".

📄 exemplo-1.html
<!DOCTYPE html> <html lang="pt-BR"> <head> <meta charset="UTF-8"> <title>Exemplo onclick</title> </head> <body> <button onclick="alert('Você clicou no botão')">Clique Aqui!</button> </body> </html>
✅ Copiado!
2 Evento onchange onchange

📌 Descrição:

O evento onchange é disparado quando o valor de um elemento é alterado (ex: selecionar uma opção em um select).

Funcionamento: Ao selecionar uma opção, uma caixa de alerta exibe a opção escolhida.

📄 exemplo-2.html
<!DOCTYPE html> <html lang="pt-BR"> <head> <meta charset="UTF-8"> <title>Exemplo onchange</title> <script> function selecionarOpcao() { var selectElement = document.getElementById('meuSelect'); var opcaoSelecionada = selectElement.options[selectElement.selectedIndex].text; alert('Opção selecionada: ' + opcaoSelecionada); } </script> </head> <body> <h1>Exemplo de onchange</h1> <p>Escolha uma opção:</p> <select id="meuSelect" onchange="selecionarOpcao()"> <option value="opcao1">Opção 1</option> <option value="opcao2">Opção 2</option> <option value="opcao3">Opção 3</option> </select> </body> </html>
✅ Copiado!
3 Evento onload onload

📌 Descrição:

O evento onload é disparado quando a página termina de carregar.

Funcionamento: Ao carregar a página, uma caixa de alerta é exibida automaticamente.

📄 exemplo-3.html
<!DOCTYPE html> <html lang="pt-BR"> <head> <meta charset="UTF-8"> <title>Exemplo onload</title> <script> function exibirMensagem() { alert('A página foi totalmente carregada!'); } </script> </head> <body onload="exibirMensagem()"> <h1>Conteúdo da Página</h1> <p>Esta é uma página de exemplo.</p> </body> </html>
✅ Copiado!
4 Eventos onmousedown / onmouseup onmousedown / onmouseup

📌 Descrição:

O evento onmousedown é disparado quando o botão do mouse é pressionado. O evento onmouseup é disparado quando o botão do mouse é solto.

Funcionamento: Ao pressionar o botão, a cor muda. Ao soltar, a cor volta e um alerta é exibido.

📄 exemplo-4.html
<!DOCTYPE html> <html lang="pt-BR"> <head> <meta charset="UTF-8"> <title>Eventos do Mouse</title> <style> #botaoClique { padding: 10px 20px; font-size: 16px; background-color: #3498db; color: #fff; border: none; cursor: pointer; transition: background-color 0.3s ease-in-out; } #botaoClique:hover { background-color: #2980b9; } #botaoClique:active { background-color: #1f618d; } </style> </head> <body> <h1>Exemplo de Eventos de Clique</h1> <button id="botaoClique" onmousedown="alterarCorPressionado()" onmouseup="alterarCorLiberado()" onclick="realizarAcao()"> Clique Aqui! </button> <script> function alterarCorPressionado() { document.getElementById('botaoClique').style.backgroundColor = '#1f618d'; } function alterarCorLiberado() { document.getElementById('botaoClique').style.backgroundColor = '#2980b9'; } function realizarAcao() { alert('Ação realizada!'); } </script> </body> </html>
✅ Copiado!
5 Interação com prompt prompt / alert

📌 Descrição:

prompt() exibe uma caixa de diálogo para entrada de dados do usuário. alert() exibe uma mensagem.

Funcionamento: Ao carregar a página, pergunta o nome e exibe um cumprimento personalizado.

📄 exemplo-5.html
<!DOCTYPE html> <html lang="pt-BR"> <head> <meta charset="UTF-8"> <title>Cumprimento Personalizado</title> </head> <body> <script type="text/javascript"> var nome = prompt("Qual é o seu nome?"); alert("Olá, " + nome + "!"); </script> </body> </html>
