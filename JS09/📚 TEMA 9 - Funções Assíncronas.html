Funções Assíncronas

📖 Conceitos 📝 12 questões ⚡ async | await | Promises | Timers

⚡ O que são Funções Assíncronas?

💡 Analogia: Imagine que você está em um restaurante. Você faz o pedido (função assíncrona) e enquanto a comida não fica pronta (resposta da API), você pode fazer outras coisas (continuar executando o código). Quando a comida fica pronta, você recebe uma notificação e pode continuar o processo.

Uma função assíncrona (async function) é um tipo especial de construção de código que facilita a execução de operações assíncronas de maneira mais conveniente e legível. Essas operações incluem tarefas como fazer solicitações de rede, ler arquivos, aguardar temporizadores e outras atividades que podem levar algum tempo.

📌 Como funciona: JavaScript pode continuar tratando outras tarefas enquanto uma operação assíncrona aguarda sua conclusão. Quando o resultado fica disponível, o código associado à operação pode continuar.
🔑 Palavras-chave:
  • async - declara que a função é assíncrona e sempre retorna uma Promise
  • await - espera o resultado de uma Promise naquela função
  • Promise - representa um valor que pode estar disponível no futuro
  • try...catch - trata erros em operações assíncronas
💡 Importante: Uma função declarada com async sempre retorna uma Promise. Isso conecta diretamente os conceitos de async, Promise e await.
async function exemplo() { return "Olá"; } // Retorna uma Promise

📦 Promises

Uma Promise (promessa) é um objeto que representa a conclusão ou falha de uma operação assíncrona. Ela pode estar em um dos três estados:

Estado Descrição Exemplo
⏳ Pendente Estado inicial, a operação ainda não foi concluída Aguardando resposta da API
✅ Realizada (resolvida) A operação foi concluída com sucesso Dados recebidos da API
❌ Rejeitada A operação falhou Erro na requisição
💡 Analogia: Uma Promise é como uma promessa que alguém faz. Ela pode ser:
  • Cumprida → a pessoa cumpriu a promessa
  • Quebrada → a pessoa não cumpriu a promessa
  • Pendente → ainda não sabemos o que vai acontecer
✅ O que são resolve e reject?
  • resolve() → indica que a operação foi bem-sucedida
  • reject() → indica que a operação falhou

💡 Exemplo: Promise = "Eu ainda não tenho o resultado, mas vou te entregar depois: com sucesso (resolve) ou com erro (reject)."

📄 promise-exemplo.js
// ============================================================ // TRABALHANDO COM PROMISES // ============================================================ // 1. Criando uma Promise manualmente const minhaPromise = new Promise(function(resolve, reject) { // resolve → indica sucesso // reject → indica falha let sucesso = true; if (sucesso) { resolve("✅ Operação concluída com sucesso!"); } else { reject("❌ Operação falhou!"); } }); // 2. Usando a Promise com then() e catch() // then() → executado no sucesso // catch() → executado no erro minhaPromise .then(function(resultado) { console.log(resultado); }) .catch(function(erro) { console.log(erro); }); // 3. Promise com setTimeout (simulando operação demorada) function esperar(ms) { return new Promise(function(resolve) { setTimeout(function() { resolve("⏰ " + ms + "ms se passaram"); }, ms); }); } esperar(2000).then(function(mensagem) { console.log(mensagem); });
✅ Copiado!
💡 then/catch e async/await são duas formas de trabalhar com Promises.
  • then/catch → outra forma de trabalhar com Promises
  • async/await → sintaxe mais legível para trabalhar com Promises
  • Ambas fazem a mesma coisa: lidam com operações assíncronas

⚡ async e await

💡 Ordem de aprendizado recomendada:
  1. Promise → entenda o conceito
  2. Timers → veja assincronicidade na prática
  3. async/await → simplifique o código
  4. fetch() → aplique em APIs reais

📌 Exemplo com setTimeout (mais simples)

📄 async-await-simples.js
// ============================================================ // ASYNC/AWAIT - Exemplo com setTimeout // ============================================================ // 1. Função que retorna uma Promise com setTimeout function esperar() { return new Promise(function(resolve) { setTimeout(function() { resolve("✅ Pronto!"); }, 2000); // 2 segundos }); } // 2. Função assíncrona usando await async function executar() { console.log("⏳ Esperando..."); // await espera o resultado da Promise antes de continuar ESTA função // (mas o JavaScript pode executar outras tarefas enquanto espera) let resultado = await esperar(); console.log(resultado); console.log("✅ Execução finalizada!"); } // 3. Executando a função executar();
✅ Copiado!
💡 Entendendo o exemplo:
  • esperar() → retorna uma Promise que será resolvida após 2 segundos
  • await esperar() → espera o resultado da Promise antes de continuar aquela função
  • Enquanto espera, o JavaScript pode executar outras tarefas
  • Quando a Promise é resolvida, o código continua

📌 Exemplo com try...catch (tratamento de erros)

📄 async-try-catch.js
// ============================================================ // ASYNC/AWAIT com try...catch (tratamento de erros) // ============================================================ // 1. Função que pode falhar function buscarDados() { return new Promise(function(resolve, reject) { let sucesso = false; setTimeout(function() { if (sucesso) { resolve("📦 Dados recebidos!"); } else { reject("❌ Erro ao buscar dados!"); } }, 1500); }); } // 2. Função assíncrona com try...catch async function executarBusca() { try { console.log("⏳ Buscando dados..."); let dados = await buscarDados(); console.log(dados); } catch (erro) { // Captura o erro se a Promise for rejeitada console.log(erro); } } executarBusca();
✅ Copiado!
⚠️ ERRO COMUM: Utilizar await dentro de uma função que não é async.

💡 Exceção: Em módulos JavaScript (arquivos .mjs ou com type="module"), é possível usar await no nível superior (top-level await).

⏰ Temporizadores

Os temporizadores são funções que permitem executar código após um determinado tempo ou em intervalos regulares. Eles são fundamentais para entender operações assíncronas.

Função Descrição Exemplo
setTimeout() Executa uma vez após o tempo especificado setTimeout(fn, 2000)
setInterval() Executa repetidamente a cada intervalo setInterval(fn, 1000)
clearTimeout() Cancela um setTimeout() clearTimeout(id)
clearInterval() Cancela um setInterval() clearInterval(id)
📄 temporizadores.js
// ============================================================ // TEMPORIZADORES // ============================================================ // 1. setTimeout - executa uma vez após o tempo console.log("⏳ Início"); setTimeout(function() { console.log("✅ Mensagem exibida após 2 segundos!"); }, 2000); // 2. setTimeout com parâmetros function saudacao(nome) { console.log("Olá, " + nome + "!"); } setTimeout(saudacao, 3000, "Ana"); // 3. Cancelando um setTimeout let timeoutId = setTimeout(function() { console.log("Esta mensagem não será exibida"); }, 5000); clearTimeout(timeoutId); console.log("⏹️ Timeout cancelado!"); // 4. setInterval - executa repetidamente let contador = 0; let intervalId = setInterval(function() { contador++; console.log("⏱️ Contador:" + contador); if (contador === 5) { clearInterval(intervalId); console.log("⏹️ Intervalo finalizado!"); } }, 1000);
✅ Copiado!
💡 Resumo dos temporizadores:
  • setTimeout() → executa uma vez após o tempo
  • setInterval() → executa repetidamente a cada intervalo
  • clearTimeout() → cancela um setTimeout
  • clearInterval() → cancela um setInterval
  • O tempo é sempre em milissegundos (1000ms = 1 segundo)

🌐 fetch() com async/await

Agora que você já entende Promises, timers e async/await, vamos aplicar esses conceitos em uma situação real: fazer requisições para uma API usando fetch().

📌 O que é fetch()? É uma função que faz requisições HTTP e retorna uma Promise. Combinado com async/await, fica muito mais fácil trabalhar com APIs.
📄 fetch-async.js
// ============================================================ // FETCH COM ASYNC/AWAIT + TRY...CATCH // ============================================================ // 1. Função assíncrona para buscar dados de uma API async function obterUsuarios() { try { console.log("⏳ Buscando usuários..."); // Passo 1: Faz a requisição para a API let resposta = await fetch("https://jsonplaceholder.typicode.com/users"); // Passo 2: Verifica se a resposta foi bem-sucedida if (!resposta.ok) { throw new Error("❌ Erro na requisição!"); } // Passo 3: Converte a resposta para JSON let dados = await resposta.json(); // Passo 4: Exibe os dados console.log("✅ Usuários recebidos:"); console.log(dados); } catch (erro) { // Passo 5: Captura qualquer erro console.log("❌ Erro:", erro.message); } } // 2. Executando a função obterUsuarios();
✅ Copiado!
💡 Fluxo do fetch() com async/await (passo a passo):
  1. await fetch(url) → aguarda a resposta da API
  2. resposta.ok → verifica se a requisição foi bem-sucedida
  3. await resposta.json() → converte a resposta para JSON
  4. catch (erro) → captura qualquer erro (rede, API, etc.)
💡 Observação importante: Este exemplo combina vários conceitos:
  • async/await → facilita a leitura do código
  • try...catch → trata erros de forma elegante
  • fetch() → faz a requisição HTTP
  • resposta.json() → converte a resposta

É normal sentir um pouco de dificuldade no início - isso é avançado!

🎯 Resumo das Funções Assíncronas

⚡ async/await

Facilita a escrita de código assíncrono

async function nome() {
  let dados = await fetch(url);
}

📦 Promise

Representa um valor futuro

new Promise((resolve, reject) => {
  resolve(valor);
});

⏰ Temporizadores

Executam código após um tempo

setTimeout(fn, ms);
setInterval(fn, ms);

🛡️ try...catch

Tratamento de erros em async/await

try {
  await operacao();
} catch (erro) {
  // trata erro
}
